# Hardware Specs Scraper

A simple Python script to get PC parts info (CPU, GPU, Motherboard) from the web and save them in organized folders.

## Features
- **Get Specs:** Scrapes info for CPU, GPU, and Motherboard.
- **Save Files:** Saves all details in `.txt` files.
- **Auto Organize:** Moves files automatically to folders (`CPU`, `GPU`, `M_BOARD`, `Extra`).
- **Save Path:** Saves your folder path in `path.txt` to use it next time.

## Built With
- **Python 3**
- **Selenium / undetected_chromedriver**
- **OS & Shutil modules**
